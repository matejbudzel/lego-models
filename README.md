# LEGO Models

A small collection of LEGO/LDraw model experiments.

## Kockáreň

The `kockaren/` folder contains LDraw (`.ldr`) drafts for a brick-built **KOCKÁREŇ** wordmark intended as a visual starting point for the Kockáreň project.

Files:

- `kockaren-v1.ldr` — first 5×7-ish pixel-font prototype built entirely from 1×1 bricks.
- `kockaren-v2.ldr` — taller, thicker construction-style prototype with more room for diagonal/structural refinements and detached diacritics.

Both drafts currently use standard 1×1 bricks (`3005.dat`) so they are intentionally easy to import and modify in BrickLink Studio / LDraw-compatible tools.

### Current color scheme

- K — red
- O — yellow
- C — blue
- K — green
- Á — red
- R — blue
- E — yellow
- Ň — green

### Direction

The next iterations should prefer believable LEGO construction over a literal pixel font: combine longer bricks where useful, improve diagonal strokes, keep letters sturdy/readable, and leave intentional spacing around the diacritics.
